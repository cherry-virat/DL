# Deep Learning-Based 3D Brain Tumor Detection, Segmentation and Quantitative Analysis Using MRI Images

## Team Members
- Cherry
- Nandu

## Project Description
This project detects brain tumors from 3D MRI images, segments the tumor region, classifies the tumor type, and performs quantitative analysis such as volume, diameter, and location.
